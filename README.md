# POC/exploration

Exploratory TypeScript proof of concept for modern digital
identity and Verifiable Credential concepts.

## Areas Explored

- Verifiable Credentials
- Issuer / Holder / Verifier model
- W3C Verifiable Credentials concepts
- OID4VCI concepts
- OID4VP concepts
- SD-JWT / SD-JWT VC concepts
- DID concepts
- did:web
- did:key
- Credential verification
- Digital wallet concepts

## Goal

Explore how portable digital identity and verifiable credentials
can be integrated into secure web applications and API workflows.

## Technology

- TypeScript
- Node.js
- REST APIs
- JWT / JWS
- JSON
- Cryptographic verification concepts

> This repository is an exploratory proof of concept and is not
> intended to represent production deployment or client work.
